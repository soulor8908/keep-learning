# 物料库自动化改造（v2）

## 核心原则

**一个命令 = 零手动配置**。物料名是唯一输入，所有配置自动派生。

## 当前痛点（9 步手动操作）

1. 创建 `demo/vue2-widgets/src/OrderPanel/OrderPanel.vue`
2. 创建 `demo/vue2-widgets/src/OrderPanel/index.js`
3. 修改 `demo/vue2-widgets/src/index.js` 添加导出
4. 修改 `demo/host/src/App.vue` 的 WIDGET_REGISTRY
5. 修改 `demo/host/vite.config.js` 的 WIDGET_MAP
6. 修改 `demo/host/index.html`（如果需要新运行时）
7. 修改根 `package.json` 的 build:widgets
8. 重新构建
9. 重启 dev server

**目标：1 步完成以上全部。**

## 设计方案

### 1. 物料命名规范

物料名即全局变量名，格式：`bi{PascalCase}`

```
输入：order-panel
派生：
  - 组件名：OrderPanel.vue
  - UMD 全局名：biOrderPanel
  - CSS 命名空间：biOrderPanel
  - 文件路径：src/widgets/order-panel/
```

### 2. 目录结构（每个物料库）

```
demo/vue2-widgets/
├── package.json
├── vite.config.js              # 自动扫描 src/widgets/ 下所有物料
├── src/
│   ├── index.js                # 自动生成：扫描 widgets/ 目录
│   └── widgets/
│       ├── sales-panel/
│       │   ├── index.js        # 自动生成
│       │   └── SalesPanel.vue  # 开发者手写
│       └── order-panel/
│           ├── index.js        # 自动生成
│           └── OrderPanel.vue  # 开发者手写
```

### 3. vite.config.js 自动扫描

不再硬编码物料列表，自动扫描 `src/widgets/` 目录：

```js
// demo/vue2-widgets/vite.config.js
import fs from 'fs';
import path from 'path';

const widgetsDir = path.resolve(__dirname, 'src/widgets');
const entries = {};
for (const dir of fs.readdirSync(widgetsDir)) {
  entries[dir] = path.resolve(widgetsDir, dir, 'index.js');
}

export default defineConfig({
  build: {
    lib: {
      entry: entries,
      formats: ['umd'],
      fileName: (chunkInfo) => chunkInfo.name
    }
  }
});
```

**效果**：添加新物料目录 = 自动参与构建，无需改 vite.config.js。

### 4. 物料库 index.js 自动生成

`src/index.js` 自动扫描 `src/widgets/` 并导出所有物料：

```js
// demo/vue2-widgets/src/index.js — 自动生成
import { createVue2Widget } from '@wc/core/templates/vue2';

const widgets = {};
const requireContext = import.meta.glob('./widgets/*/index.js', { eager: true });

for (const [path, mod] of Object.entries(requireContext)) {
  const name = path.match(/\.\/widgets\/(.+)\/index\.js/)[1];
  const kebabToPascal = name.split('-').map(s => s[0].toUpperCase() + s.slice(1)).join('');
  const globalName = `bi${kebabToPascal}`;
  widgets[globalName] = mod.default;
}

export default widgets;
```

**效果**：添加新物料目录 + 入口文件 = 自动导出，无需改 index.js。

### 5. Host 注册表（手动维护，跨仓场景）

Host 和物料库是不同代码仓，注册表由宿主团队维护。物料库只需提供 UMD 产物 + 命名规范。

```js
// demo/host/src/App.vue — 宿主团队手动维护
const WIDGET_REGISTRY = {
  biSalesPanel: {
    name: 'biSalesPanel',
    js: '/widgets/vue2-widgets/biSalesPanel.js',
    cssNamespace: 'biSalesPanel',
    vueVersion: '2'
  },
  biOrderPanel: {
    name: 'biOrderPanel',
    js: '/widgets/vue2-widgets/biOrderPanel.js',
    cssNamespace: 'biOrderPanel',
    vueVersion: '2'
  },
  // ...
};
```

**约定**：物料库按 `bi{PascalCase}` 命名，Host 按规范注册。

### 6. CLI 脚本：pnpm add:widget

```bash
pnpm add:widget --name order-panel --lib vue2 --ui element-ui
```

脚本执行：
1. 创建 `demo/vue2-widgets/src/widgets/order-panel/OrderPanel.vue`（模板）
2. 创建 `demo/vue2-widgets/src/widgets/order-panel/index.js`（模板）
3. 运行 `pnpm build:widgets`（重建所有物料库）
4. 输出成功信息

**开发者只需手写 OrderPanel.vue 的模板和逻辑。**

### 7. 物料模板（自动生成的文件）

#### OrderPanel.vue（骨架）

```vue
<template>
  <div class="order-panel">
    <h3>{{ title }}</h3>
    <!-- 开发者在此添加内容 -->
  </div>
</template>

<script setup>
defineProps({
  title: { type: String, default: '订单面板' },
  emit: { type: Function, default: () => {} }
});
</script>

<style scoped>
.order-panel { padding: 16px; }
</style>
```

#### index.js（自动生成）

```js
import OrderPanel from './OrderPanel.vue';
import { createVue2Widget } from '@wc/core/templates/vue2';

export default createVue2Widget(OrderPanel, {
  plugins: window.ELEMENT ? [window.ELEMENT] : [],
  deps: ['element-ui']
});
```

### 8. Host vite.config.js 映射

```js
// demo/host/vite.config.js
const WIDGET_LIBS = ['vue2-widgets', 'vue3-widgets', 'h5-widgets'];

const WIDGET_MAP = {};
for (const lib of WIDGET_LIBS) {
  WIDGET_MAP[`/widgets/${lib}.js`] = path.resolve(__dirname, `../${lib}/dist/${lib}.js`);
}
```

**效果**：添加新物料库 = 只改 WIDGET_LIBS 数组，无需逐个映射。
