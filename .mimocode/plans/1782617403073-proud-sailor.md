# Bug 修复 + 功能补全

## 修复清单

### 1. loadScript 缓存拒绝的 promise（`wc/loader.js`）
**问题**：`cache.set(url, p)` 在构造 promise 之前执行，网络闪断后 rejected promise 被永久缓存，重试永远失败。
**修复**：将 `cache.set` 移到 promise 构造之后，或在 catch 中从 cache 删除。

### 2. loadStyle 并发重复注入（`wc/loader.js`）
**问题**：`cache.set` 在 promise 构造之后，快速连续调用时两次都通过 `has` 检查，产生两个 `<link>` 标签。
**修复**：与 loadScript 一致，先 set cache 再构造 promise。

### 3. WidgetHost findWidget 跳过安全检查（`wc/WidgetHost.vue`）
**问题**：通过命名空间找到的物料直接调用 `mod.mount`，绕过了依赖检查、CSS 加载、emit 桥接。
**修复**：findWidget 找到物料后，仍然走 `mountWidget` 的安全路径，或手动注入 emit。

### 4. i18n 缺少 `common.events`（`demo/host/src/App.vue`）
**问题**：6 个物料都渲染了 `t('common.events')`，但 messages 中没有这个 key。
**修复**：在 zh-CN 和 en-US 中添加 `'common.events': '事件'` / `'common.events': 'Events'`。

### 5. ChartWidget 硬编码 "Refresh"（`demo/h5-widgets/.../ChartWidget.js`）
**问题**：刷新按钮文字硬编码英文，未走 `t()` 函数。
**修复**：改为 `t('common.refresh')`。

### 6. parseWidgetMeta 从未调用（`wc/loader.js`）
**问题**：函数已定义但代码中从未使用，是死代码。
**修复**：删除 `parseWidgetMeta` 函数和相关注释。

## 涉及文件

| 文件 | 改动 |
|------|------|
| `wc/loader.js` | 修复 loadScript/loadStyle 缓存顺序，删除 parseWidgetMeta |
| `wc/WidgetHost.vue` | findWidget 路径注入 emit |
| `demo/host/src/App.vue` | 添加 common.events key |
| `demo/h5-widgets/src/widgets/chart-widget/ChartWidget.js` | Refresh 改为 t() |
